# Code of Conduct

## Our pledge

We are committed to making participation in CINE Universal a respectful, constructive and professional experience for everyone.

## Expected behavior

Be respectful, assume good faith, focus criticism on ideas and implementation, document technical decisions, and help keep discussions useful for the project. Harassment, discrimination, threats, intimidation, deliberate disruption, and publication of private information are not acceptable.

## Enforcement

Project maintainers may remove or edit contributions that violate this code and may restrict participation when necessary to protect the project community. Reports should be made privately through the repository's available maintainer or GitHub reporting channels.

This code of conduct is intended to support the project license and contribution guidelines, not replace them.
