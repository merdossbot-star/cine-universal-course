Déploiement

GitHub Pages d’abord. Vercel comme alternative.

Le site est statique : pas besoin de serveur CINE pour la documentation. GitHub Pages suffit pour le cours et les iframes locales ; Vercel est idéal si vous voulez une chaîne Git avec previews automatiques.

A · GitHub

Déployer sur GitHub Pages

Créer le dépôt
Créez par exemple cine-universal-course et poussez le contenu du ZIP à la racine.
Activer Pages
Dans Settings → Pages, choisissez GitHub Actions comme source de publication.
Le workflow est déjà fourni
.github/workflows/pages.yml
Push sur main
Le workflow construit et publie le site à chaque push sur main.
git init
git add .
git commit -m "docs: CINE universal course"
git branch -M main
git remote add origin https://github.com/<OWNER>/cine-universal-course.git
git push -u origin main
GitHub Pages prend en charge la publication depuis une branche ou via un workflow GitHub Actions. La documentation officielle recommande les workflows personnalisés lorsque vous voulez contrôler le processus de build. Voir la documentation GitHub Pages.
B · Iframes

Oui, deux iframes peuvent vivre sur la même page.

La démo utilise deux URLs locales : examples/compare/react/index.html et examples/compare/cine/index.html. C’est plus robuste que de dépendre d’une iframe vers un autre domaine qui peut envoyer des headers de sécurité empêchant l’embed. Le frame React charge uniquement son runtime CDN.

<iframe src="examples/compare/react/index.html"></iframe>
<iframe src="examples/compare/cine/index.html"></iframe>
C · Vercel

Utiliser le même dépôt GitHub.

New Project
Importez le dépôt GitHub dans Vercel.
Framework
Choisissez “Other”/site statique si nécessaire ; il n’y a pas de build obligatoire.
Root directory
Si le site est à la racine, utilisez la racine ; s’il est sous site/, sélectionnez site.
Deploy
Chaque push peut ensuite déclencher une nouvelle deployment et Vercel fournit des preview URLs.
Vercel documente l’import direct de dépôts GitHub et le déploiement automatique sur les pushes/PRs, avec des environnements de preview. Voir Vercel Git.
npm i -g vercel
vercel login
vercel link
vercel deploy
vercel deploy --prod
D · Recommandation

GitHub pour la source, Vercel pour la vitesse.

GitHub Pages

Parfait pour la documentation publique, les cours et la démonstration statique.

Vercel

À privilégier si vous voulez des previews automatiques, des déploiements plus intégrés et la possibilité d’ajouter plus tard des fonctions server-side.
