Le sélecteur cherche dans le registre des frameworks et packages. Chaque exemple montre l’intention, le code source, puis le comportement dans deux iframes indépendantes.

Exemple 01 · UI + état

React et son alternative CINE

Les deux cadres réalisent la même intention : afficher un compteur et modifier l’état au clic. Dans la version CINE, l’événement devient une instance universelle avec ses variables indépendantes.

React 18.3.1live iframe
CINE alternativelive iframe

React

const [count, setCount] = useState(0);
<button onClick={() => setCount(c => c + 1)}>
  Compteur {count}
</button>

CINE

button.increment
  kind: event
  vars: count, progress
  on click → update state
  → writer text

Exemple 03 · Slicing

Trois packages, trois usages, un runtime réduit.

Scénario pédagogique : une application importe trois packages et n’utilise qu’un symbole de chacun. Le JSDK doit distinguer package déclaré, symbole utilisé et dépendances transitives.

import { parse } from "csv-parse/sync";
import { debounce } from "lodash-es";
import { format } from "date-fns";

const rows = parse(input);
const saveLater = debounce(save, 300);
const stamp = format(new Date(), "yyyy-MM-dd");

csv-parse

parse()

Entrypoint retenu : parse + fermeture transitive.

lodash-es

debounce()

Entrypoint retenu : debounce + dépendances nécessaires.

date-fns

format()

Entrypoint retenu : format + modules nécessaires.
