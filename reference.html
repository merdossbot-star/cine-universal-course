HTMLX 4.0.0

Slot d'intégration préparé.

Le projet fourni dans la conversation ne contient pas une spécification/source identifiable d’« HTMLX 4.0.0 ». Le site réserve donc une entrée d’adapter pour cette cible, mais ne prétend pas certifier des APIs dont la source exacte n’a pas été fournie. Le jour où le package/source est versionné, il doit passer par le même pipeline : acquisition → parse → semantic model → dictionary → CINE IR → proof.
