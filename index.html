Le modèle mental

CINE n’est pas une réécriture d’un framework.

CINE est la source de vérité. Les frameworks deviennent des frontends d’analyse, les plateformes deviennent des backends, et le dictionnaire organise les capacités sans confondre les identités.

CINE source
  → validation par automates
  → parsing / expansion
  → semantic IR
  → relation graph
  → linker / slicing
  → target lowering
  → build / proof

Principe de production

Un fichier utilisé doit être mesurable.

Le JSDK ne doit pas embarquer une framework entière si une page n’utilise qu’une fonction. CINE suit les imports, les bindings, les symboles et les dépendances transitives pour produire une empreinte minimale quand la preuve le permet.
